## Capture instructions

1. Resolve resource/build blockers in [SETUP.md](SETUP.md).
2. Launch the app on an emulator or real device.
3. Capture actual app screens, not concept art or generated mockups.
4. Remove usernames, email addresses, test passwords, notifications, and personal data from screenshots.
5. Add screenshots under `docs/screenshots/` and update this file with embedded images.

Example Markdown, **only after** a real screenshot is uploaded:

```markdown

```

Do not publish a screenshot as an implemented feature until the screen is actually verified.
