## Portfolio project summary

**Wanderlust — Android Travel Itinerary Prototype**

A Kotlin-based Android prototype using Jetpack Compose to present destination travel guides and support basic local account registration and login. It includes selectable Bali, Paris, and Singapore destination cards, separate day-by-day itinerary screens, Activity/Intent navigation, and a SQLiteOpenHelper-backed user data flow.

**Status:** Source-reviewed historical project. Current repository requires resource fixes and build verification. Personalized itinerary generation and travel tracking are not confirmed as implemented features.
